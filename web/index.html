    How It Works

    01SETUP (ONE TIME)

    02OPTIONAL (RECOMMENDED)

    • Add the control panel as an OBS Custom Browser Dock:

    03HOW DELAY WORKS

    1. Start streaming from OBS while DelayDeck is open.
    2. To add delay, click a preset (15s/30s/…) or enter a custom value and press Set.
    3. DelayDeck must first build a buffer equal to the delay you requested.
    4. To remove delay, set it back to 0s (or use Skip to live).
    5. When you stop streaming in OBS, the buffered seconds still play out before your stream ends.

    04TEST WITHOUT GOING LIVE

    1. In Settings, choose Test as the destination. Nothing is sent to any platform.
    2. Start streaming in OBS (the stream key can be anything).
    3. Press Watch output on the Control tab and compare it with OBS's preview: change the delay, skip to live, and see exactly what viewers would get.
